Microsoft account sign-in

Your account stays
yours.

Vitra uses the official Microsoft sign-in, so players can launch the copy of Minecraft they own. You sign in on Microsoft's own website, never inside Vitra.

  1. Sign in on Microsoft's websiteOAuth device code flow at login.microsoftonline.com/consumers, scope XboxLive.signin offline_access.
  2. Xbox LiveUser authentication, then XSTS for rp://api.minecraftservices.com/.
  3. Minecraft services/authentication/login_with_xbox exchanges the Xbox token for a Minecraft access token.
  4. Ownership & profile/entitlements/mcstore and /minecraft/profile confirm the game is owned and read the player's name and UUID.
  5. Skins, capes and namesThe profile skin, cape and name endpoints, only when the player changes their own skin, cape or name, or checks whether a name is free.

What Vitra never does

  • See, ask for or store your Microsoft password.
  • Send your account data anywhere except Microsoft and Mojang. Tokens stay on your PC, encrypted with a key in Windows Credential Manager.
  • Track you. There are no analytics, ads or telemetry.
  • Unlock the game for accounts that don't own it. Those can only start the official demo.
